# DeskMosaic · 桌面拼图

DeskMosaic 把实时字幕、截图录屏、Markdown 笔记和音频切换放在一个入口里。macOS 从菜单栏打开，Windows 从系统托盘打开。开会时可以在本机转写系统声音和麦克风，做演示时可以只录屏幕的一块，换耳机时也能一键把输入和输出一起切过去。

打开控制中心会先看到总览。左侧显示当前播放设备、麦克风和可拖动的音量条；中间可直接框选截图，右侧可一键切换配对的输入和输出设备。「打开快速笔记」续写最近的快速笔记，第一次使用会创建「随手记」，「打开笔记本」回到上次的笔记。「打开录写与翻译」先打开工作窗口，由你选择何时开始录写。详细设置位于窗口底部的分页。

## 下载

| 平台 | 安装包与要求 |
| --- | --- |
| macOS | 在 [Releases](https://github.com/icysplendor/DeskMosaic/releases) 下载 Apple Silicon DMG，打开后将应用拖到「应用程序」。内置录写／翻译引擎需要 macOS 13.3 或更新版本。 |
| Windows | 在 [Releases](https://github.com/icysplendor/DeskMosaic/releases) 下载 Windows x64 EXE，适用于 Windows 10／11。发布包自带 .NET 运行时，笔记窗口需要 Microsoft Edge WebView2 Runtime。 |

临时签名的 macOS 构建可能需要在「隐私与安全性」中点「仍要打开」。按使用的功能授予权限。截图、录屏和电脑声音采集需要屏幕与系统音频录制权限，麦克风单独授权，独立鼠标滚轮需要辅助功能权限。当前 Windows 构建可能显示 SmartScreen 提示。

## 录写和翻译

从菜单栏或托盘打开「录写／翻译」，选择电脑声音、麦克风，或两个一起用。字幕在独立窗口实时更新，可以调整原文和译文字号，查看每段的起止时间。只想抄录时，勾选默认关闭的「仅记录」。「录音」默认开启并记住你的选择，启动会话后录下所选音源，结束后把 WAV 保存到下载文件夹。会话启动后立即请求采集音频，模型加载时先在内存暂存，识别就绪后按顺序补处理。关闭「录音」时，暂存的音频只用于字幕。

点「开始」使用选定的源语言和目标语言。要让中文段落翻成英文、英文段落翻成中文，点「互译」。互译需要中英流式识别模型和文本翻译模型。字幕可按原文、译文或双语导出为 Markdown，每段开头标注相对录音或导入音频起点的起止时间。「清屏」确认后会清除当前字幕和待导出的文字，录音照常进行，已保存的文件会保留。

也可以在音源菜单选「导入音频」或拖入一个音频文件。支持 WAV、MP3、M4A、AAC、FLAC、OGG、Opus、AIFF 和 WebM。点「开始」或「互译」后，每识别完一段就翻译这一段，后面的音频继续识别。优先选用支持所选语言的 1920 ms 模型。安装说话人模型后，导入的音频也会标注说话人。导入模式会禁用录音开关。处理成功后，底部只显示「音频执行完毕」。切换回实时音源时会恢复开始、互译和原有录音设置。关闭窗口后，下次会恢复原来的实时音源。

第一次使用，在「设置 → 录写／翻译」下载所需模型。软件会校验下载并自动选中，也支持手动选择匹配的模型文件。

应用内下载优先使用面向国内网络的入口。Hy-MT3 使用腾讯在 ModelScope 的官方权重，LMT-60、MOSS 和说话人模型使用 HF-Mirror，语音识别模型使用 GitHub 下载加速服务 ghproxy.net。遇到网络错误、超时或文件大小、SHA-256 校验失败时，软件会自动改用对应的 Hugging Face 或 GitHub 原地址。

| 用途 | 选择 |
| --- | --- |
| 实时语音识别 | X-ASR 160 ms 支持中英混说。韩语、法语可分别下载对应的 Zipformer 模型。 |
| 文本翻译 | 默认用腾讯混元 Hy-MT3 1.8B，也可选小牛翻译 LMT-60 0.6B。使用过 Hy-MT2 的用户可在设置中下载 Hy-MT3。窗口里的语言选项会随已配置的模型变化。 |
| 段末复核 | 可选 X-ASR 1920 ms 或 MOSS 0.9B Q8（约 987 MB，单独下载）。MOSS 可以把一段转写拆成多位说话人的发言。 |
| 区分说话人 | 可加装 Nemotron 说话人模型，双击字幕下方的说话人标签可以改名。 |

在「设置 → 录写／翻译 → 段末复核」下载 MOSS，然后用录音右侧的「高级复核」图标开关，选择会保存。未安装 MOSS 时无法开启，两个复核模型都未安装时图标会提示。实时字幕和语种选择沿用原有流式识别。实时换人只在内部划分发言，字幕仍按停顿、标点或长度换段。普通翻译和互译分别翻译每次发言，再按顺序接到同一张字幕卡片。每段结束后，MOSS 在后台复核整段原始音频并区分说话人。能对齐的短句也会进入复核。所有新段的译文就绪后，独立的字幕卡片会一次性替换原段，每张卡片在自己的时间右侧显示「MOSS 已复核」。等待或翻译失败时保留原字幕和已显示的译文。仅记录时复核完成即可替换。相邻的同一人发言会合并。开启流式说话人模型后，复核通过时间线匹配整场会话的说话人编号，匹配不明确时显示「说话人待确认」。实时字幕保留内部发言边界，出字时隐藏说话人。未配置流式说话人模型时，MOSS 编号仅在原段范围内有效。Markdown 导出沿用字幕的分段。

麦克风默认使用温和的人声检测，可切换均衡或关闭，也可以延长断句等待。原始 WAV 仍记录所选音源。识别和翻译在本机运行。翻译自动尝试 macOS Metal 或 Windows Vulkan，也可以手动选 CPU。

## 截图和区域录屏

截图设置分为「截图标注」和「录屏文件」。框选后，浮条从左到右依次提供标注工具、颜色和粗细、尺寸与撤销、保存和完成。录屏中可以切换「操作桌面」继续使用其他应用，点「停止」后可打开视频或定位到文件夹。

- **截图**可跨显示器拖框，也可悬停选窗、输入精确像素尺寸。选区内支持画笔、矩形、箭头、文字和马赛克。标注可移动、撤销。工具栏最右侧的「完成」将截图复制到剪贴板，左侧相邻的「录屏」开始录制选区。「保存」可导出 PNG。
- **录屏**从截图选区开始。选区固定后，仍可操作桌面，随时切换到绘图工具给视频加标注。停止后生成 H.264 MP4。可在截图设置里调分辨率、帧率、码率、缓存和保存位置。区域录屏只录画面和标注，录声音可用「录写／翻译」里的 WAV 功能。

## 笔记本

笔记是保存在本地的 Markdown 文件，默认目录为文稿下的 `AssistantNotebook`。支持可编辑预览、源码编辑、检索、表格、待办和附件。长代码块可以弹出到独立窗口编辑。删除的笔记本、笔记和附件集中放在回收站。

可以给「快速笔记」和「打开上次笔记」设置全局快捷键。需要多设备同步时，可选择绑定专用的 Nextcloud HTTPS WebDAV 目录。两边都改过时会保留两个版本供你对照。仓库还提供可独立部署的网页笔记本。 [笔记本使用与部署说明](Notebook/README.md)

## 音频和系统工具

经常在音箱、耳机和会议麦之间切换，可以把一台输出设备和一台输入设备存成一个配置组，再从菜单或快捷键整组切换。设备可以分别记住音量，也能锁定首选输入或输出。菜单栏和托盘会显示当前输出音量。不用这项功能时，可关掉音频中心。

macOS 还可以切换显示器分辨率和刷新率，单独设置外接鼠标的滚轮方向，触控板继续使用系统设置。两个平台都提供可自定义的快捷键、中英文界面、浅色／深色主题和登录启动选项。

## 反馈与开发

实时翻译默认每隔 1.5 秒可对每路音源的未完句请求一次预览，期间合并原文更新。可在「设置 → 录写／翻译 → 文本翻译」调整间隔（0.5 至 10 秒，每档 0.5 秒），下次开始会话时生效。识别确认新的句末时可提前翻译，定稿优先。

可在「设置 → 录写／翻译」开启「诊断日志（保存到下载）」，查看模型和引擎状态，以及每次翻译的缓存命中率、输入处理耗时和译文生成耗时。日志文件为 `Translation-diagnostics-*.log`，不含录音或字幕正文。反馈问题时请附系统版本、软件版本和复现步骤。 [提交问题](https://github.com/icysplendor/DeskMosaic/issues)

- **macOS** 用 Xcode 打开 `MACAssistant.xcodeproj`，运行 `MACAssistant` scheme。Apple Silicon 上可用 [构建脚本](scripts/build-release.sh) 生成包含运行库的 DMG。
- **Windows** 用 .NET 8 SDK 构建 `WinAssistant/WinAssistant.csproj`。完整打包步骤可参考 [GitHub Actions 工作流](.github/workflows/build.yml)。
- **GitHub Actions** 从 `Build and Release → Run workflow` 手动运行，可勾选一个或两个平台。只构建时可从 Actions 下载产物，勾选创建 Release 后会发布所选平台的安装包。
- 平台差异、配置和数据行为见 [功能规范](spec.md)。
